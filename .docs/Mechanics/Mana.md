The fuel for active abilities — and it only exists during battle.

## Rules

- **Per-battle pool** — resets to full at the start of each combat
- **Actives cost mana only in battle**
- **Outside battle, active abilities are free** — no mana spent
- Mana is **not** a character sheet stat; the encounter state manages it

## Where it lives

- Created when a combat encounter starts
- Spent as actives are used via `use_ability` ([[Mechanics/Action Tools]])
- Discarded when the encounter ends; the next battle starts fresh

> There's no way to raise, drain, or trade mana — it's a per-fight budget that forces choices about when to use actives.
