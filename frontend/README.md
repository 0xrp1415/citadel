# Citadel Frontend

The Citadel client — a browser SPA built with React (Vite), Tailwind CSS, and TanStack Router.

## Prerequisites

- **Node.js** ≥ 22
- **pnpm** ≥ 11

## Setup

```sh
pnpm install
```

## Scripts

| Command | What it does |
|---|---|
| `pnpm dev` | Starts the Vite dev server on `http://localhost:5173` with HMR |
| `pnpm build` | Type-checks (`tsc -b`) and builds the production bundle to `dist/` |
| `pnpm lint` | Runs oxlint |
| `pnpm preview` | Serves the built `dist/` locally |

## Routing

File-based routing via TanStack Router. Route files live in `src/routes/`; `routeTree.gen.ts` is generated by the Vite plugin (`@tanstack/router-plugin`).

| Path | File | Screen |
|---|---|---|
| `/` | `src/routes/index.tsx` | Home — identify yourself |
| `/lobby` | `src/routes/lobby.tsx` | Staging grounds — create/join an expedition |
| `/run` | `src/routes/run.tsx` | The descent — live run (placeholder) |

If you add or rename route files, the route tree regenerates automatically on `pnpm dev` / `pnpm build`.

## Folder structure

```
frontend/
  .oxlintrc.json          # oxlint rules (routes dir exempted from fast-refresh rule)
  index.html              # SPA entry HTML
  vite.config.ts          # Vite + React + Tailwind + TanStack Router plugins
  tsconfig.json           # project references
  tsconfig.app.json       # app TS config
  tsconfig.node.json      # Vite/config TS config
  public/
    favicon.svg
  src/
    index.css             # Tailwind import + base styles
    main.tsx              # entry: createRouter + RouterProvider
    routeTree.gen.ts      # generated route tree (committed)
    routes/
      __root.tsx          # root layout (Outlet + nav)
      index.tsx           # /
      lobby.tsx           # /lobby
      run.tsx             # /run
```
